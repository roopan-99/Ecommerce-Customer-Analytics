> insights with SQL, Python and Power BI.**

## Project Overview

An end-to-end analytics project focused on understanding **sales
performance, customer behaviour, RFM segmentation, geographic patterns
and product metrics** from transactional e-commerce data.

### Analytics Flow

**Transactions → Data Cleaning → SQL Analysis → Customer Features → RFM
Segmentation → Power BI Model → Interactive Dashboard**

## RFM Segmentation

The project uses the three standard RFM dimensions:

  Metric          Meaning
  --------------- -------------------------------------
  **Recency**     How recently a customer purchased
  **Frequency**   How often a customer purchased
  **Monetary**    How much value a customer generated

Customer profiles include **Champions, Loyal Customers, New / Promising,
At Risk, Need Attention, Cannot Lose Them and Hibernating**.

## Analytical Workflow

1.  **Prepare the data** --- clean and validate transactional records.
2.  **Create customer features** --- derive purchase frequency, monetary
    value and purchase timing.
3.  **Perform RFM analysis** --- classify customers into actionable
    behavioural segments.
4.  **Analyse with SQL** --- answer business questions using structured
    queries and aggregations.
5.  **Build the Power BI model** --- create measures and relationships
    required for reporting.
6.  **Develop the dashboard** --- combine KPIs, trends, segmentation and
    geographic insights.

## Business Questions

-   Which customers may need retention or re-engagement?
